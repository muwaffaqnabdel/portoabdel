# Abdel — Creative Developer Portfolio

Starter homepage built with React, Vite, Tailwind CSS v4, Motion, Lenis, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Personalize before publishing

1. Add your portrait at `public/profile.jpg`.
2. Replace `Abdell Muwaffaq N.` with your exact preferred full-name spelling if needed.
3. Update the email address (`hello@example.com`) and social profile URLs in `src/App.jsx`.
4. Replace the project placeholder visuals with actual screenshots and verify project descriptions/technologies.
5. Update education and experience dates in the Journey section.
6. Review the page on mobile and desktop.

## Deploy to Vercel

Push this folder to a GitHub repository, import the repository in Vercel, and use the default Vite settings:
- Build command: `npm run build`
- Output directory: `dist`

The Vercel subdomain is free; a custom domain is optional.
